# ASA DATAFEST: PATIENT'S WAIT TIME 🕒
**By My Ha**

## Introduction
This project analyzes the factors that impact patients' wait time (measured as the number of days between visits) in an anonymous healthcare system in Kansas.

The dataset was provided for the ASA DataFest competition hosted at Loyola University Chicago.

## Note on Data & Code
Since ASA DataFest 2026 is still ongoing in other regions, the dataset and analysis code are not included in this repository at this time.
